Apri o recupera

Apri sostituisce l’archivio in lavoro. Unisci aggiunge le schede e, dopo conferma, sostituisce i duplicati. Ricarica risolve i conflitti rileggendo il file sul PC.

Esporta un elenco

Con una selezione esporti solo le schede scelte. Senza selezione esporti i risultati filtrati. Per ripristinare tutto usa il backup completo.

Assistenza e log

Se qualcosa non funziona, esporta il registro e invialo insieme al nome del pulsante premuto.

Registro automatico degli ultimi 300 eventi del browser e degli eventi disponibili del server locale. Esclude chiavi, token, contenuto delle schede e messaggi grezzi dei servizi. Sul PC resta anche data/diagnostica.jsonl.

Salvataggio automatico su file con l’assistente locale. Nel browser resta una copia di emergenza: conserva anche un backup JSON.

Screenshot / ScreenAI

Carica o incolla una schermata, oppure importa un file .screenai.json con immagine e analisi. Puoi analizzare adesso o archiviare senza IA e valutare in seguito.

PNG, JPEG, WebP: massimo 4 MB per immagine. Su PC puoi incollare uno screenshot con Ctrl+V in questa finestra. Il file ScreenAI si importa senza eseguire una nuova analisi.

L’analisi integrata richiede l’assistente PC e un modello che supporti immagini. La schermata viene inviata soltanto quando premi Analizza e confermi. L’archiviazione senza analisi funziona anche offline. Il backup JSON include le immagini: conserva una copia completa.

Usare ScreenAI su Windows
  1. Nel pacchetto è incluso il sorgente ScreenAI 1.8: compila con compila-portatile.bat.
  2. Dal menu dell’icona scegli Cattura idea per Repo Atlas, oppure usa la normale analisi.
  3. Nel risultato premi Esporta per Repo Atlas e salva il file .screenai.json.
  4. Importa quel file qui e premi Archivia da valutare.

L’immagine esportata è quella effettivamente inviata all’IA, con gli eventuali oscuramenti dell’anteprima.

Impostazioni e collegamenti

Stato configurazione salvata

IA e controllo ZIP richiedono AVVIA_WINDOWS.bat sul PC (Python 3.10+). Su GitHub Pages queste due funzioni richiedono l’assistente locale; catalogo, GitHub e backup Google restano disponibili con i rispettivi requisiti.

Aspetto e account

I miei progetti contiene soltanto i repository archiviati il cui proprietario coincide con questo account. Usa Importa miei repository pubblici nella raccolta per aggiungerli senza sostituire le tue note.

Intelligenza artificiale

Le analisi richiedono AVVIA_WINDOWS.bat sul PC. Ollama non richiede una chiave; OpenRouter usa «openrouter/free» per testi e immagini con limiti gratuiti. Groq ha limiti del piano gratuito, che dipendono dall’account. Le chiavi restano solo in memoria: vanno reinserite dopo il ricaricamento. Una foto richiede un modello che accetti immagini. Verifica prima di analizzare: possono esserci limiti o costi secondo il piano e modello scelti.

Google Drive e Sheets

Il Client ID identifica l’app; il token autorizza temporaneamente il tuo account. Non serve inserire un token a mano: salva il Client ID, poi premi Collega Google. Il token ottenuto resta soltanto in memoria e può scadere.

Come configurare Google, passo per passo
  1. Apri il tuo progetto in Google Cloud e abilita Google Drive API. Per esportare fogli abilita anche Google Sheets API.
  2. Configura la schermata di consenso e gli eventuali utenti di test.
  3. Crea un Client ID OAuth di tipo applicazione web.
  4. Tra le origini JavaScript autorizzate inserisci esattamente questa origine, senza il percorso del repository:
  5. Copia il Client ID qui sopra e premi Salva configurazione. Non usare un client secret.
  6. Riapri Impostazioni, premi Collega Google e completa il consenso. Poi esegui il backup dalla sezione Backup ed esportazioni.

Guida agli errori e alle soluzioni

Il codice identifica il tipo di problema. Le indicazioni distinguono le cause accertate dalle possibilità da controllare.

I log non includono chiavi, token o contenuti delle schede. Il registro ha un limite di 300 eventi nel browser; cancellare i dati del sito cancella anche questo registro.

Salva ed esci

Salva il file completo prima di chiudere. Il backup Drive è facoltativo. Il backup comprende l’intero archivio, README, analisi, note e configurazione non segreta.

Se manca la rete o Google rifiuta l’accesso, il file locale resta disponibile e il backup Drive rimane indicato come da fare.
